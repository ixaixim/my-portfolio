# Neel Misciasci: personal website

Source of <https://ixaixim.github.io/my-portfolio/>, a static site (plain HTML, CSS and JavaScript, no build step) served by GitHub Pages.

| File | Content |
|---|---|
| `index.html` | Home: photo, bio, contact links, rolling project bar |
| `publications.html` | Publications & Talks |
| `script.js` | Project data (edit here to add or change projects) and the project bar/dialog logic |
| `style.css` | Shared styles, including dark mode |
| `images/` | Project figures and `profile.jpg` |

## Preview locally

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
